# 見出し

## レベルが1ずつ増える見出し

## スペースが1つある見出し

## スペースを1つに直した見出し

次の見出しの前に空行を置く。

## 空行ありの見出し

- ハイフンのリスト
- ハイフンに統一したリスト

- 親リスト
  - インデントが2スペースの子リスト
  - インデントが2スペースの子リスト

行末の半角スペースを削除した

本文のハードタブを半角スペースに直している。

[正しいリンク](https://example.com) は検出されない。

[リンク先のあるリンク](https://example.com) は検出されない。

本文とコードフェンスの間に空行を置く。

```go
func main() {
	// コードブロック内のタブは検出しない（code_blocks: false）
}
```

本文とリストの間に空行を置く。

- 埋もれていないリスト
