# ダッシュボードの形式

## 1. 役割

ダッシュボードは、1 つの `.rikai/` フォルダにある全資料の学習状態を 1 枚にまとめた、読むだけの HTML である。`study.md` の frontmatter だけを元に `scripts/build_dashboard.py` が組み立てる。モデルは画面の中身を書かない。

状態の正本は各 `study.md` であり、ダッシュボードは何も書き換えない。論点を手動で卒業にする操作は、画面からではなくスキルへの指示で行う（[study-format.md](study-format.md) §3）。

## 2. 置き場と生成

| 指定 | 読む範囲 | 出力先 |
|---|---|---|
| `--rikai-dir <.rikai>`（またはそれを含むフォルダ） | その `.rikai/` の `*.study.md` | `<.rikai>/dashboard.html` |
| `--root <起点>` | 起点の配下にあるすべての `.rikai/` の `*.study.md`（`node_modules` と `.git` は見ない） | `<起点>/.rikai/dashboard.html` |

```bash
python3 "<SKILL_DIR>/scripts/build_dashboard.py" --rikai-dir "<.rikai フォルダ>" --lang ja
python3 "<SKILL_DIR>/scripts/build_dashboard.py" --root "<起点のフォルダ>" --lang en
```

終了コードは 3 つある。0 は全件読めた。1 は入力の誤り（フォルダがない、指定の重複など）。2 は読めない `study.md` があった。2 のときもダッシュボードは書かれ、読めなかった資料はカードに理由が表示される。

既定の `--rikai-dir` を使う。`--root` は、ユーザーがフォルダをまたいだ一覧を求めたときだけ使う。

出力は決定的である。同じ `study.md` の集まりからは常に同じ HTML になる。生成時刻は埋め込まず、「最新の挑戦日時」で代える。

## 3. 画面の構成

上から次の順に並ぶ。

1. 全体の集計: 資料数、論点の総数、状態ごとの件数（卒業・復習中・要再抽出）
2. 資料ごとのカード: 資料名、状態の割合を示すバーと件数、挑戦済みの論点数と最新の挑戦日時。続けて、次回の復習対象、誤読の多い段落、論点ごとの記録（折りたたみ）、リンク（絵解きノート・テキストブック・`study.md` の生データ）
3. 手動で卒業にした論点: 資料名、題名、日時、理由

カードは資料名の順に並ぶ。`--root` では、起点からの相対フォルダを資料名の前に付ける（`chapters/ch2/report` など）。

次回の復習対象は、誤答を経験した `復習中` の論点の題名である。前回の挑戦が誤答だった論点を先に、あとは論点 id の順に並べる。未挑戦の論点は含めない。

誤読の多い段落は、[study-format.md](study-format.md) §5 の還流レポートと同じ規則で集計し、上位 5 件を出す。誤答回数の降順、最終誤答日時の降順、論点 id の昇順で、同じ段落に結び付く論点の題名をまとめて示す。

論点ごとの記録は、折りたたみ（`details`）の中に全論点を並べる。各論点は題名、状態（手動の卒業は「卒業（手動）」）、正解と誤答の回数を 1 行で示す。開くと挑戦履歴（日時・正誤・観点・問題文）が古い順に読める。手動の卒業は日時と理由、`要再抽出` は出題対象外である旨を添える。`study.md` を直接開かなくても記録を読めるようにするためで、生の `study.md` へのリンクは「生データ」と明示する。

リンクの対象は 3 つで、実在するものだけを出す。絵解きノート（`.explainer.html`）。テキストブック（`.explainer.pdf`。なければ原稿の `.explainer.tex`）。`study.md` の生データ（`.study.md`）。

論点 id（`topic-NNN`）は画面に出さない。

## 4. 読めない study.md の扱い

読めない `study.md` とは次のようなものである。frontmatter が [study-format.md](study-format.md) §2.1 の範囲を外れている。必須のキーがない。状態の値が 3 種のいずれでもない。これらは「読み取れませんでした」として理由つきでカードに出す。ほかの資料は通常どおり載せる。スキルは終了コード 2 を見たら、ユーザーに資料名と理由を伝える。`study.md` を直すのは、その資料でスキルを起動したときである。

## 5. 言語

固定の文言は日本語と英語をスクリプトに内蔵している。`--lang` にはユーザーの言語の言語タグを渡す（SKILL.md §2）。日本語と英語以外は英語で表示される。状態の値（`復習中`、`卒業`、`要再抽出`）は、絵解きノートと同じ訳語で表示する（英語なら `Reviewing`、`Mastered`、`Needs re-extraction`）。

資料名、論点の題名、見出しパス、引用は `study.md` の値をそのまま出す。訳さない。
