# yorisoi 適用例（Before / After）

`meiseki:yorisoi` を実際の日本語にかけた例。各例は `NN-name.before.md`（原文）と
`NN-name.after.md`（やさしい日本語化後）の対で置いてある。
YLS（やさしさ負荷スコア。低いほどやさしい）は SKILL.md §7 の式による実測値。
語彙判定の目標レベルは既定の N4 相当（推定値）。

| # | 例 | 主に効いたカテゴリ | YLS (before → after) |
|---|---|---|---|
| 01 | 会場のお知らせ | YB 二重否定 / YC 受身 / YD 推測 / YE 敬語 / YA 文長 | **300.0 → 0.0** |
| 02 | 健診の案内（表記） | YG 元号・範囲記号・24時間表示・日付 / YF 略語 | **133.3 → 0.0** |
| 03 | 避難のお願い（語彙） | YF 語彙超過（vocab-check で機械検出）/ ＜＝説明＞形式 | **200.0 → 0.0** |

> 再現方法：プラグインルートで次を実行する。
>
> ```bash
> # textlint 側(ガイドライン構文の検出)
> npm run lint:yorisoi -- examples/yorisoi/01-notice.before.md
> # 語彙レベル側(目標 N4)
> npm run vocab:yorisoi -- examples/yorisoi/01-notice.before.md
> ```

## 01. 会場のお知らせ ── 二重否定・受身・推測・敬語

**Before**

> 市民の皆様へのお知らせです。会場ではマスクの着用が求められますので、ご協力をお願い申し上げます。
>
> なお、雨天の場合は開催されないおそれがありますが、中止の場合も連絡が来ないわけではありませんので、ご安心ください。
>
> ご不明な点がございましたら、市役所までお越しください。

**After**

> 市民の皆さんへのお知らせです。会場では、マスクをつけてください。
>
> 雨の日は、中止になるかもしれません。中止のときは、連絡があります。
>
> わからないことがあるときは、市役所に来てください。

直したところ：

- YB 二重否定：「連絡が来ないわけではありません」→「連絡があります」（真偽を反転させない）
- YC 受身：「着用が求められます」→「マスクをつけてください」（読者への指示に立て直す）
- YD 推測：「開催されないおそれがあります」→「中止になるかもしれません」
- YE 敬語：「申し上げます」「ございましたら」「お越しください」を丁寧語に落とす
- 検出の内訳：prh 6 件（A1 ×1・YC/YD/YE ×5）＋ 一文長 1 件 ＋ 語彙超過 1 語（求める）

## 02. 健診の案内 ── 表記規則と略語

**Before**

> 次回の健診は令和7年3月10日に実施します。受付は9時〜11時30分、結果の説明は14時から行います。
>
> 申込期限は2025/2/28です。

**After**

> 次の健康診断は、2025年3月10日にします。受付は、午前9時から午前11時30分までです。
>
> 結果の説明は、午後2時からです。申し込みは、2025年2月28日までにしてください。

直したところ：

- YG 表記：元号→西暦、「9時〜11時30分」→「から…まで」、「14時」→「午後2時」、「2025/2/28」→「2025年2月28日」（すべて prh が機械検出）
- YF 略語：「健診」→「健康診断」（ガイドラインの書き換え例）

## 03. 避難のお願い ── 語彙レベルと「＜＝説明＞」形式

**Before**

> 当該地域では余震の発生の蓋然性が高いため、迅速な避難の実施をお願いします。避難に際しては、貴重品の携行は最小限にとどめてください。

**After**

> この地域では、余震＜＝後から来る地震＞が起きるかもしれません。早く逃げてください。
>
> 逃げるときは、大切な物だけを持ってください。

直したところ：

- YF 語彙：textlint の指摘は 0 件で、**vocab-check だけが問題を検出する例**。
  超過 2 語（迅速・とどめる）に加え、リスト外 5 語（当該・蓋然性・携行など）が参考として挙がる。
  「迅速な避難の実施」→「早く逃げてください」のように、目標レベルの語彙へ言い換える。
- 「余震」は言い換えると意味が壊れる重要語なので、ガイドラインの
  「余震＜＝後から来る地震＞」形式で残して説明を付ける（after ではリスト外の参考扱いになり、超過には数えない）。
