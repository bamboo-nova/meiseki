# やさしい日本語 書き換えカタログ YA–YH

「在留支援のためのやさしい日本語ガイドライン」（出入国在留管理庁・文化庁、2020年8月）の
規則を、書き換えパターンとして**優先度順 YA→YH**でカタログ化する。
各項目は **問題 / Before / After / 注意**。対応する機械検出（textlint ルール・prh・vocab-check）を併記する。
検出が無いカテゴリは LLM が判断する。

ガイドラインの構成: ステップ1（日本人にわかりやすい日本語にする）→
ステップ2（外国人にもわかりやすい日本語にする）。YA・YH がステップ1、YB〜YG がステップ2に対応する。

## YA. 一文一義・短く切る
textlint: `sentence-length`(max 50), `max-ten`(max 3), `no-doubled-conjunctive-particle-ga`
（ガイドライン ステップ1「一文を短くして、簡単な構造にする」）

一つの文には一つの内容だけを入れる。文が長いと、外国人読者は構造を頭で保持できない。

- **問題**：一文に複数の内容が詰まっている。
- **Before**：申請書は市役所で配布していますが、郵送を希望される場合は封筒を送っていただければ対応いたしますので、ご検討ください。
- **After**：申請書は市役所で配ります。郵送もできます。郵送がいい人は、封筒を送ってください。
- **注意**：ガイドライン自体は文字数の基準を示していない。max 50 字は本スキルの実務値であり、
  超過の指摘は「切れないか検討する」合図として使う。回りくどい言い方
  （「〜ということになります」「調査を実施した」）も、このカテゴリで同時にほどく
  （`ja-no-redundant-expression` が一部を検出する）。

## YB. 二重否定を畳む
textlint: `no-double-negative-ja` ＋ prh A1 補完（分離型・丁寧形）
（ガイドライン ステップ2「二重否定の表現は使わない」）

- **問題**：否定が二重に掛かり、結論の向きが読めない。
- **Before**：申請できないわけではありません。
- **After**：申請できます。（条件があるなら「ただし、〜が必要です」と続ける）
- **注意**：**真偽を反転させない。** 「影響がないとは言えません」は「影響することがあります」であり、
  「影響しません」に畳むのは誤訳。meiseki 本体の A1 と同じ基準で畳む。

## YC. 受身・使役を能動にする
prh: YC（「〜されます」「〜させられ」の近似検出。誤検知があるため LLM が文脈判断）
（ガイドライン ステップ2「受身形・使役表現はできるだけ使わない」）

- **問題**：受身文は「誰がするのか」が消え、外国人読者に負荷が大きい。
- **Before**：会場でマスクの着用が求められます。
- **After**：会場では、マスクをつけてください。
- **Before**：作文を書かされます。
- **After**：先生が「作文を書いてください」と言います。
- **注意**：prh の検出は近似で、可能形・自発の「される」も拾う（例「思い出される」）。
  受身でない指摘は無視してよい。自然な受身（被害の受身「財布を盗まれました」）は、
  動作主が不明なら残してよい。

## YD. 推測・曖昧・多義を消す
prh: YD（おそらく／〜と思われます／〜おそれがあります／〜ようです／結構です／等）
（ガイドライン ステップ2「推測の表現は使わない」「曖昧な表現は避ける」）

- **問題**：推測・ぼかし表現は、読者に「結局どうなのか」を判断させる。
- **Before**：雨天の場合は中止になるおそれがあります。
- **After**：雨の日は、中止になるかもしれません。
- **Before**：ゴミは決められた日に出していただければ結構です。
- **After**：ゴミは、決められた日に出してください。
- **注意**：分かっていることは言い切る。分からないことは「〜かもしれません」と書く
  （このため `ja-no-weak-phrase` は無効にしてある。「かもしれません」は削る対象ではない）。
  「など」「ぐらい」は多用しない。対象を書けるなら列挙する。

## YE. 敬語は丁寧語だけにする
prh: YE（いらっしゃる／召し上がる／ご覧／お越し／申し上げる／伺う／ございます）
textlint: `no-mix-dearu-desumasu`（文末は「です・ます」に統一）
（ガイドライン ステップ2「敬語は丁寧語を使う」）

- **問題**：尊敬語・謙譲語は形の変化が大きく、学習途上の読者には別の単語に見える。
- **Before**：市長がお見えになり、ご挨拶を申し上げます。
- **After**：市長が来ます。市長が挨拶をします。
- **注意**：文末は「です・ます」。指示は「〜してください」と書く（「〜しましょう」にしない）。
  丁寧さは保つ。ぞんざいな言い切り（常体）にはしない。

## YF. 語彙をやさしくする
vocab-check（同梱リストで語彙レベルを機械判定）+ `max-kanji-continuous-len`(max 4)
（ガイドライン ステップ1「外来語に気をつける」、ステップ2「簡単な言葉を使う」「漢語より和語」）

- **問題**：漢語・専門用語・略語・カタカナ語は、目標レベルの読者の語彙に無いことが多い。
- **Before**：当該書類を至急提出してください。
- **After**：この書類を、すぐに出してください。
- **Before**：健診の受診をお願いします。
- **After**：健康診断を受けてください。
- **言い換えられない重要語**：ガイドラインの「そのまま残して説明を付ける」形式を使う。
  - **Before**：余震に注意してください。
  - **After**：余震＜＝後から来る地震＞に注意してください。
- **注意**：
  - vocab-check の「超過」は書き換え候補、「リスト外」は参考。固有名詞は判定対象外。
  - 語彙リストは推定値（JLPT 公式リストは非公開）。判定はあくまで起点であり、
    最終判断は LLM が文脈で行う。
  - 外来語は、定着している語（バス・テレビ）は残してよい。定着していない語
    （インフラ・スキーム等）は言い換える。国語研『「外来語」言い換え提案』が参考になる。
  - 略語は開く（「健診」→「健康診断」）。

## YG. 表記をそろえる
prh: YG（元号／範囲記号「〜」／24時間表示／日付スラッシュ）
（ガイドライン ステップ2・別冊の表記規則）

- 元号 → 西暦：「令和2年7月10日」→「2020年7月10日」
- 「〜」 → 「から…まで」：「10時〜12時」→「10時から12時まで」
- 24時間表示 → 午前/午後：「18時」→「午後6時」
- 日付の「/」 → 年月日：「2020/7/10」→「2020年7月10日」
- ローマ字表記（Yasashii Nihongo のような）は使わない（LLM 判断）
- **注意**：ふりがな・分かち書きは本スキルのスコープ外（v0.6.0 時点）。

## YH. 構造で伝える
textlint: なし（LLM 判断）
（ガイドライン ステップ1「文書は一文書一情報」「箇条書きを活用」、ステップ2「大切な情報を先に」）

- **問題**：大切な情報が文書の後ろに埋まっている。並列の項目が一文に埋もれている。
- **方針**：
  - 結論・読者がすべきことを文書の先頭に置く。
  - 3つ以上の並列項目は箇条書きに開く（meiseki の F と同じ原理）。
  - 見出しで「何の話か」を示す。
- **注意**：箇条書き化は体裁の変更であり、情報・順序は変えない。

## 全体の検算

書き換え後、目標レベルの読者になったつもりで通読する。

- **意味が変わっていないか**が最優先。やさしくした結果、条件・例外・数値が落ちていたら復元する。
- 二重否定（YB）の畳み込みは、論理の向きが原文と一致しているか最後にもう一度確認する。
- 固有名詞・連絡先・日時・金額は原文のまま（表記規則 YG の変換を除く）。
- 「＜＝説明＞」を付けた語は、説明が原文の意味と一致しているか確認する。説明の創作はしない。
- textlint と vocab-check を再実行し、YLS（SKILL.md §7）が before より下がったことを確認する。
